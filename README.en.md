# dsh-up-session

[简体中文](./README.md) | English

A simple DeepSeek Harness sidebar plugin: it inserts a "Pinned" section above the "Workspaces" list and gathers pinned sessions from all workspaces into one place.

Clicking a row in the pinned section opens that session. If its workspace is collapsed (or any ancestor workspace within a "workspace tree" group is collapsed), those workspaces are expanded first, then the session opens.
