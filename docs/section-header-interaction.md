# 置顶区与最近区标题行交互

状态：已实现。

## 已确认的规则

置顶区和最近区的标题行与 DSH 原生工作区标题行保持一致：鼠标悬停时显示原生的悬停背景色。

鼠标未悬停时，置顶区保留置顶图标，最近区保留时钟图标。鼠标悬停整行标题时，左侧图标替换为原生工作区使用的展开／收起箭头，方向反映分组当前的展开或收起状态。

箭头必须沿用当前原生主题实际使用的图标，不能固定为某个版本的图形。主题改变原生箭头时，置顶区与最近区的箭头也同步改变，包括运行期间切换主题的情况。

移除目前紧跟标题文字的旧箭头，展开／收起提示统一由左侧悬停时出现的原生箭头承担。

## 原生能力核对

DSH 原生工作区使用 `@deepseek-ai/dsh-client-ui-primitives` 导出的 `IconTriangleRightFillRegular`。该组件引用宿主共享的 SVG symbol，主题通过宿主的 `theme/change` 机制更新 symbol。直接复用该组件即可跟随主题，无须复制当前 SVG 路径、观察原生工作区行或另行监听主题变化；即使没有原生工作区行也能显示。

## 交互边界

悬停范围覆盖整行，包括右侧设置入口。鼠标停在设置入口上时，整行继续保持悬停背景，左侧继续显示方向箭头；点击设置入口只打开设置，不切换分组。

本次只调整标题行的悬停样式和箭头。整行点击展开／收起、两个分组的默认展开状态及现有状态保存方式沿用当前行为；键盘操作和触摸操作继续可用，不额外引入不同于原生的图标触发规则。

## 验证

现有 29 项回归测试全部通过。另在本地浏览器预览中，使用实际标题行组件与样式，以及从宿主前端产物提取的原生图标工厂，验证默认图标与箭头切换、展开收起、齿轮区域悬停、设置点击不折叠分组和键盘收起。

主题同步通过在预览中替换同 ID 的共享 SVG symbol 验证：原生图标参考与标题行箭头同步更新，悬停背景也随主题颜色变量更新。这项验证模拟宿主的资源替换机制，未在运行中的 DSH 应用里安装插件或切换主题。
