# 最近区只收未置顶的会话，与置顶区互斥

「最近」区按最近更新时间收拢会话，但不包含已经置顶的会话：一个会话要么出现在置顶区，要么出现在最近区，不会两处都有。

这是唯一被认真权衡过的方案。另一种做法是让最近区成为「全部会话按更新时间排序」的视图，置顶会话也照常出现在其中。否决的原因是，两个区上下相邻，同一行在两处重复出现会让人以为列表出了问题；置顶区本身已经承担了「这些会话最近有动静」的提示职责，重复显示不带来额外信息。

代价是「最近」不再等于「全部会话的最近」。用户若想找刚聊过但已置顶的会话，要去置顶区看——置顶区同样按最近更新时间排序，所以它就在那个区的顶部。ADR 0001 记的是同一条原则的另一面：置顶区是快捷入口，不把会话从原项目列表里移走；而最近区是收拢入口，只收置顶区没接手的那部分。
