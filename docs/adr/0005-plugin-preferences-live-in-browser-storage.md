# 插件的设置保存在浏览器本地存储

插件的设置弹窗只有一项偏好「展开工作区中的原会话」，默认开启。值保存在 `localStorage` 的 `dsh-up-session/preferences.v1` 键下，是一个 JSON 对象；缺失、损坏或读不到存储时回落到默认值。读取只发生在组件挂载时，开关每次点击都立即写入并生效，没有保存按钮。

选择本地存储而不是宿主的设置文档，原因有三点。插件是纯 Client 侧边栏装饰，Host 侧只是一个空 `apply()`；要把偏好放进 Host 设置，需要给插件增加 Schemastery 配置、确认该条目的设置命名空间会被服务端投影，并处理在线改写配置时的插件重载语义。这项偏好只影响本插件的点击行为，不参与任何 Host 能力，跨浏览器同步也不是需求。最后，同一个 profile 里其他第三方插件也把浏览器本地偏好放在 `localStorage`，这样本插件与它们的做法一致。

代价是设置按浏览器（来源）保存：换浏览器、换来源端口或清空站点数据都会回到默认开启；它也不会同步到其他设备。键名带 `v1`，将来改变记录形状时可以迁移或换键，而不是误读旧值。`writePreferences` 目前整体覆盖记录；新增字段时必须先合并已有记录，否则会丢掉旧值。
