# 从最近隐藏采用随新活动失效的浏览器本地记录

用户需要暂时整理最近区，同时保留会话在原工作区中的归属、标题、历史、置顶及归档状态。因此「从最近隐藏」只改变最近区的收录，使用独立于宿主会话数据和插件偏好的浏览器本地记录；不借用归档，也不采用永久排除名单，以便会话出现新活动后自然回到最近区。该功能来自 [PR #4](https://github.com/kyrsieger/dsh-up-session/pull/4)。

记录保存在 `localStorage` 的 `dsh-up-session/muted-from-recent.v1` 键下，只包含会话 ID 与隐藏时的最近更新时间。当前更新时间不大于记录值时，最近区排除该会话；时间推进后，该记录不再阻止它显示，但它仍须满足未置顶、未归档等收录条件。设置中的「恢复」清空全部记录，不修改宿主会话状态。

代价是隐藏只在当前浏览器来源生效，换浏览器或清除站点数据后不再保留，也不会跨设备同步。记录缺失、损坏或不可读时视为没有隐藏，写入失败时只保留当前组件内的效果；新活动使记录失效时不会删除该记录，因此设置显示的数量是保留的记录数，而非当前实际被排除的会话数。
